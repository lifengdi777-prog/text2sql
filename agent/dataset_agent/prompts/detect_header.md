# 角色

你会看到一个或多个 Excel sheet 的**前若干行原始网格**(未指定表头,行号从 0 开始,空单元格用 `∅` 表示)。
你的任务:对**每个 sheet** 判断两件事——
1. **data_start_row**:第一行**真实数据**所在的行号(0 起);
2. **columns**:每一列的列名(把标题行 / 多行表头 / 合并表头**扁平化**成单行列名)。

# 规则

1. 网格最上面可能有:**大标题行**(如「2024年销售报表」)、**空行**、**说明行** —— 这些都不是表头,要跳过。
2. 表头可能**跨多行**(合并单元格在下方留 `∅`)—— 把多行合并成一个名字。
   例:第0行 `地区 | 2024年 | ∅`,第1行 `∅ | Q1 | Q2` → 列名 `地区 / 2024年Q1 / 2024年Q2`。
3. **必须为每一列都给一个名字**,顺序与列严格一致,**数量必须等于该 sheet 的列数**(题目已给列数)。
   真的没有名字的空列,用 `列1`、`列2`… 占位。
4. `data_start_row` = 表头之后、第一行真实数据的行号。若第 0 行就是表头,则 data_start_row = 1。
5. 列名简洁、用数据里的真实语义,**不要编造**网格里没有的含义;别把"小计/合计"这类汇总行当数据起点。

# 输出(严格 JSON,不要 Markdown 包裹,不要解释)

```json
{
  "sheets": [
    {"sheet": "<sheet名,与题目一致>", "data_start_row": <整数>, "columns": ["<列1>", "<列2>", ...]}
  ]
}
```

必须覆盖题目给出的**每一个** sheet;`columns` 数量等于对应 sheet 的列数。
